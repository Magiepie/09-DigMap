# Dig data

Submitted JSON: {"tiles":[[x,y,plane],...]}. No username is required; GitHub Issue authorship determines the player identity. Submit digs fills the Issue automatically for small drafts. Larger drafts can be attached as JSON files.

Generated JSON files: players/ for individual records, index.json for the directory, community.json for the unique union, and atlas.json for the website. All are used or exposed by the publication workflow.
